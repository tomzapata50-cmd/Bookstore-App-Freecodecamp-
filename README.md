# Bookstore App - FreeCodeCamp

This repository contains a minimal Bookstore CMS-style application built to satisfy the FreeCodeCamp project requirements.

Features:
- Vite + React
- Redux Toolkit for state management (add/remove books)
- Simple, responsive UI

Getting started

1. Install dependencies

   npm install

2. Run the dev server

   npm run dev

3. Build

   npm run build

4. Run tests

   npm run test

Notes and enhancements
- This starter focuses on the core functionality: add and remove books. You can extend it with category filters, persistence (localStorage or API), routing, and improved tests.
